# Phoenix Cohort Frontend Capstone Project — Group 25.

This React web application built is part of the TS Academy Frontend Development Course. The application demonstrates modern frontend development practices including component-based architecture, With A Already laid down Figma Design to follow, responsive design, API integration, and collaborative Git workflows.

---

## Project Summary

This project recreates the provided design mockup as a fully functional React application. The application focuses on delivering an engaging user experience through responsive layouts, reusable components, dynamic content rendering, and modern frontend best practices.

The project demonstrates proficiency in:

- HTML5 Semantic Structure
- CSS3 & Responsive Design
- JavaScript (ES6+)
- React Components & Props
- State Management(UseState)
- API Integration
- Git & GitHub Collaboration
- Deployment with Vercel

## How to run Locally

2. OPen the folder On your VScode
3. open A new Terminal  
4. Clone the Repository(The one you wiah to run Locally)
5. start A new server(npm run dev) on the Terminal.
6. copy The Link (Likely should be http://localhost:5173/ ) and paste on your browser
7. The cloned Webpage should come up.
